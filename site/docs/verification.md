The endpoint returns a clear 503 when missing; no analyzed quote is fabricated. Core tests verify that valid supplied slicer measurements replace geometry estimates and retain source provenance. Studio confirmation remains required before production. Enable actual slicing only after configuring and calibrating the native service described in README.md.

WebMCP feature detection found no supported `document.modelContext` in the available browser, so native WebMCP registration/execution validation was unavailable. This optional enhancement does not affect the visible customer journeys.

The final slow-network test delayed the quote endpoint by 1.2 seconds: the browser immediately showed SAR 29 for the changed quantity, kept ordering disabled while confirmation was pending, then confirmed the same server price. An intentionally aborted upload produced a useful connection error and successfully retried. A separate mobile browser context with touch support verified that a one-finger drag changed rendered pixels. These fault injections produce an expected browser network error; no unhandled application error appeared. Admin now includes recent uploaded models and each order's full status history. Compact previews use 512 px shadow maps; the primary viewer uses 1024 px.
