# Forma3D visual direction

Three internal directions were considered:

1. **Blue air / object studio:** a pale ice-blue stage, graphite typography, one precise azure accent, an oversized tactile object and compact quiet controls. Closest to the supplied reference; excellent brand compatibility and mobile translation.
2. **Red workshop / creator store:** warm white, vivid red-orange, dense editorial object arrangements. Distinctive but less compatible with the existing turquoise logo and supplied reference.
3. **Gallery / material library:** neutral silver-white, modest cyan, sparse object studies. Clear and premium but less inviting for first-time young creators.

Selected: **Blue air / object studio**. The object's silhouette and physical layer texture carry the identity. No decorative glow, fabricated popularity, testimonials, or industrial graphics.

Palette: ice #e9f1f5; porcelain #f8fafb; graphite #20333e; azure #217fa8; muted #617680; line #d6e2e8. Stock PLA colours: red, blue, grey, black and white. Blue is the default object colour; the warm white option remains available.
Typography: Manrope for compact confident English display and readable UI; IBM Plex Sans Arabic for Arabic. Numerical values use tabular numerals.
Composition: generous stage occupying most of the first viewport; copy at upper left; sculptural vase centered; configuration column right. Ordinary page navigation and a slim local-production line. Product rail below, then an asymmetric local print statement.
Spacing: 8px base, generous 24/40/64px rhythms. Radius: 8px controls, 14px configuration surfaces; product stage corners remain restrained.
Motion: 150ms controls, 240ms panels, 700ms model arrival; no continuous decoration. Respect reduced motion.
3D: pale satin filament, closed hollow fluted geometry with a restrained, filtered print-layer bump texture, a gently elevated perspective camera, broad soft lighting and physical floor shadow. All products represented by actual procedural geometry. Uploaded files render their actual geometry.
Mobile: object above controls, readable labels, 44px touch controls, sticky price action, no hover-only functionality. RTL from the shared layout, Latin model identifiers isolated.

## October 2026 reference revision

The supplied configurator reference now controls the composition: one continuous cloud studio, a single-line 44px headline, a large floating blue object, two primary rotation buttons, small secondary camera controls and grouped translucent white option surfaces. The hero no longer competes with a marketing card grid. A horizontal object rail changes the actual geometry in place. Mobile stacks the full object stage above its controls; the five colour choices and the purchase action remain large enough to tap. Prices update immediately, then ordering waits for the matching server quote. Ender-3 V3 SE dimensions use native XYZ 220 × 220 × 250 mm; the viewer rotates file geometry only for display.
